# pds-range

<FigmaEmbed nodeId="783:6023" />

Control deslizante simple o doble (rango min-max). Implementa CVA.

## Importación

```typescript
import { PdsRangeComponent } from '@poli/components';
```

## API

### Inputs

| Input | Tipo | Default | Descripción |
|-------|------|---------|-------------|
| `type` | `'single' \| 'double'` | `'single'` | Un thumb o dos thumbs (min-max) |
| `min` | `number` | `0` | Valor mínimo del eje |
| `max` | `number` | `100` | Valor máximo del eje |
| `step` | `number` | `1` | Incremento por paso |
| `value` | `number \| null` | `null` | Valor inicial (modo single) |
| `valueMin` | `number \| null` | `null` | Valor mínimo inicial (modo double) |
| `valueMax` | `number \| null` | `null` | Valor máximo inicial (modo double) |
| `showInputs` | `boolean` | `true` | Muestra inputs numéricos laterales |
| `disabled` | `boolean` | `false` | Estado deshabilitado |
| `label` | `string \| null` | `null` | Etiqueta (modo single) |
| `labelMin` | `string` | `'Min'` | Etiqueta del input izquierdo (modo double) |
| `labelMax` | `string` | `'Max'` | Etiqueta del input derecho (modo double) |

## Uso básico

```html
<!-- Rango simple -->
<pds-range label="Porcentaje" [min]="0" [max]="100" />

<!-- Rango doble (min-max) -->
<pds-range
  type="double"
  [min]="0"
  [max]="10000000"
  [step]="100000"
  labelMin="Precio mínimo"
  labelMax="Precio máximo"
/>

<!-- Sin inputs numéricos -->
<pds-range label="Volumen" [showInputs]="false" />

<!-- Con Reactive Forms -->
<pds-range label="Nota" [min]="0" [max]="5" [step]="0.5" formControlName="nota" />
```

## Tipos de valor CVA

```typescript
// type='single' → number
rangeCtrl = new FormControl<number>(50);

// type='double' → { min: number, max: number }
rangeCtrl = new FormControl<{ min: number; max: number }>({ min: 20, max: 80 });
```

## Accesibilidad

- Cada thumb es `<input type="range">` nativo con `aria-label`, `aria-valuemin`, `aria-valuemax`, `aria-valuenow`.
- Los inputs numéricos laterales están sincronizados con los thumbs.
- Navegación con flechas del teclado.
