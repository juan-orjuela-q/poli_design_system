export function getVar(token) {
  if (typeof document === 'undefined') return '';
  return getComputedStyle(document.documentElement).getPropertyValue(token).trim();
}

## Anillos de foco

El DS v2 usa un patrón de **doble anillo**: anillo interior blanco fijo (`--action-focus-inner: #ffffff`) + anillo exterior de color según contexto.

**Patrón de uso en SCSS:**
```scss
&:focus-visible {
  outline: none;
  box-shadow:
    0 0 0 2px var(--action-focus-inner),          // anillo interior blanco
    0 0 0 6px var(--action-primary-focus-ring);   // anillo exterior — cambia según contexto
}
```

> Los colores del anillo exterior son tokens simples exportados por Style Dictionary. El patrón `box-shadow` completo es el compuesto — su estructura no cambia, solo el color exterior.

## Sombras

El sistema de sombras usa **doble capa** (soft + hard) sobre una base de color `#18274B` (azul oscuro). La escala va de 100 (mínima elevación) a 800 (máxima).

> Los tokens de sombra son valores compuestos (múltiples `drop-shadow` combinados). Figma Style Dictionary no los exporta automáticamente como custom properties — se definen manualmente en `component.css` con los valores tomados directamente de Figma.
